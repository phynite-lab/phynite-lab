# Contributing

Develop the local application here. The hosted server is a separate service;
contributions must build and run without its private source or credentials.

Please follow our [Code of Conduct](.github/CODE_OF_CONDUCT.md). To report
unacceptable behavior privately, email [support@phynitelab.com](mailto:support@phynitelab.com).

Use [Discussions Q&A](https://github.com/phynite-lab/phynite-lab/discussions/categories/q-a)
for usage questions and [Ideas](https://github.com/phynite-lab/phynite-lab/discussions/categories/ideas)
to explore proposals. For reproducible bugs or concrete feature requests, use the
[issue forms](https://github.com/phynite-lab/phynite-lab/issues/new/choose). Report
security vulnerabilities privately using the [security policy](.github/SECURITY.md).

Create a focused task branch and pull request. Run the relevant scientific and
domain tests, lint, typecheck and the local production build for code changes.
Documentation-only changes need a link/consistency review and `git diff --check`.
In the PR, state which checks ran, their outcomes, and why relevant checks were
not run. For visible UI changes, include screenshots and viewport sizes checked.
Preserve scientific inputs, units, provenance, checksums and real error states.
Never replace missing
results with fabricated or example scientific output.

Contributions are offered under this repository's GNU AGPL v3 only license.
Do not submit code or datasets you cannot redistribute. Identify third-party
origins, licenses and changes, and keep the upstream notices.

Platform support is established by real qualification evidence, not a successful
dependency solve or a unit fixture. Release changes must include exact source,
build instructions and all applicable third-party notices/source obligations.
