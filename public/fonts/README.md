Geist and Geist Mono are self-hosted from `geist@1.7.2` (Vercel), licensed under the SIL Open Font License in `Geist-LICENSE.txt`. The unmodified variable WOFF2 sources are retained for Greek, Cyrillic and scientific glyphs. Latin subsets preserve weight axes and layout features and are generated by `scripts/subset-fonts.py`; their Unicode ranges match `app/fonts.css`.

Space Grotesk is self-hosted with its SIL Open Font License in `SpaceGrotesk-LICENSE.txt`.

Fonts are served from the same origin. Regenerating the Geist subsets is an explicit maintenance task; the release build does not download fonts or run FontTools.

The landing uses separate public families with only its required glyphs and weight ranges (Geist/Mono 400–600, Space Grotesk 500–700). Full workspace families and scientific-symbol Unicode fallback ranges remain available. Regenerate all subsets with `scripts/subset-fonts.py`; subset first, then restrict variation axes.
