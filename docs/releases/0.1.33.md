# Phynite Lab 0.1.33

Restore the DFT editor composition from Jauhar's
`feat/hpc-ui-ux-and-workflow-run` branch. The configuration toolbar retains
Download, Simple/Manual and Run without the old input selector, explanatory
notices or successful-result panel inserted above it in 0.1.32.

Completed results remain available through the grouped download menu. Failed
calculations retain their execution diagnostics and recovery action. MD
trajectories remain inspectable. A result-fetch error remains visible even when the attempt was
recorded as completed; unavailable artifacts cannot remain in the download menu.

The scientific, Slurm, allocation and ZIP path corrections from 0.1.32 remain.
The package acceptance now checks the actual editor toolbar and download menu on
desktop and mobile using explicitly synthetic UI fixtures. The fixtures do not
execute a solver or represent scientific results.

Native qualification, corresponding source and post-publication installation
checks remain required for every shipped platform.
