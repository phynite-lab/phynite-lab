# Phynite Lab 0.1.29

Discovery planning, the scientific workbench and the reviewed HPC changes ship
together in this version. Selecting a Discovery preset prepares a draft; it does
not send a message or submit a calculation.

- Local workspace settings use a settings gear. Local save status uses a drive
  icon. Offline workspaces do not poll unavailable Cloud catalog or Inbox APIs.
- Project tabs retain their own row on small screens. Composer controls and
  Discovery presets remain accessible in narrow, short, split and floating views;
  Escape and outside clicks restore focus, and only one composer overlay opens.
- Saved artifacts support versioned editing and independent AI hunk review.
  Viewport evidence requires conversation consent. Canvas changes preview frozen
  coordinates before approval. Campaigns retain attempts and bounded repair policy.
- Fixed-composition Bayesian optimization and source-bound APS/PRB draft archives
  preserve method, unit, input and evidence identity.
- HPC setup uses managed private environments and explicit concurrency checks.
  Retained SCF state is checksum-verified and copied privately; upstream state is
  never hard-linked for mutation. Workflow stages remain independently scheduled.
  Resource advice is a heuristic, not a performance measurement.

The optional MACE runtime remains qualification-gated. The exact original model
and locked packages were installed on the development macOS ARM64 host, but real
qualification failed during OpenMP shared-memory initialization in the sandbox.
Installation alone does not enable MLIP calculations or qualify another platform.

Source verification includes 838 TypeScript tests, 98 native AI tests, 517 backend
tests (9 optional host skips), a separate 12-test numerical BO run, lint, typecheck,
production build and the public Python source inventory. UI inspection covers
every local route, all 12 scientific module editors, English/Indonesian, light/dark
themes, mobile/short/zoom-equivalent sizes and split/floating chat interactions.
The final audit passed 92 local route states, 98 documentation/alternative route
states, 48 module layouts plus 24 actual-dark module states, and 17 interaction
checks. Composer regression checks passed six responsive sizes with both mouse
and touch, including full-size controls after selecting a preset at 320 px.
Native package, solver, sandbox and registry acceptance must pass on each shipped
platform before publication; source tests do not replace those release gates.
