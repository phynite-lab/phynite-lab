# Phynite Lab 0.1.31

AI activity is easier to follow, and the chat controls take less space.

- Active work shows its current phase, spinner and elapsed time. Specialists
  appear inline, with technical counters available on demand. The idle task bar
  and separate Chat/Tasks tabs are removed.
- Capture, Discovery, strategy and permission controls live under **+**, beside
  the compact model picker. Capture continues after the menu closes. Discovery
  prepares a message without sending it, and keyboard focus returns to the input.
- Module changes use saved names and scientific functions. Historical verification
  boilerplate no longer lists internal `aim_…: unknown` identifiers. Core action
  verification and real pending or failed actions remain visible.
- Resizing the workspace clears stale keyboard geometry so a short viewport does
  not collapse into a blank pane or hide the composer.

Team is enabled for **Antigravity Gemini 3.8 Flash High
(`agy/gemini-3.8-flash-high`) on macOS ARM64**. The reviewed native run used
Antigravity 1.5.9 and Node 22.23.5. Two independent specialists completed with
overlapping execution; their evidence identities, revisions, checksums and counts
were reviewed against actual tool observations. Global admission, queued/stream
cancellation, Stop/restart and late-result fencing passed direct native checks.
The bundled qualification index retains exact model/platform and evidence gates.

The measured case took 157,586 ms and four provider calls in Solo, versus
369,794 ms and twelve calls in Team; each used two tools. Team was slower in this
case. These results establish neither a general speedup nor scientific accuracy.
Unmeasured usage and cost remain unavailable. Other models and platforms remain
unqualified for Team.

No WSL2 or HPC test host was available. Linux release checks do not establish WSL2
`/home` or `/mnt/c` qualification or HPC failure/transfer behavior. Notes remain
local, without cross-device cloud sync.

The release process requires native package, browser, persistence, scientific
reference, isolation and license gates on macOS ARM64, Linux ARM64 and Linux x64,
followed by clean installations from npm on all three targets. Exact corresponding
source, package checksums and collected qualification evidence accompany the
GitHub release. No hosted service is deployed.
