# Phynite Lab 0.1.30

Project Notes, connected Files and a calmer AI workspace ship together. The
scientific workspace remains the main view, with at most two permanent panes.

- The AI composer groups context, settings and Send/Stop controls. Chat and Tasks
  share the companion panel. Discovery presets prepare a draft without sending
  it. Pane/tab preferences persist, and text keeps its reading hierarchy.
- [Project Notes](../project-notes.md) provides Markdown source/preview, formulas,
  independent recoverable drafts, immutable saved revisions, local archive/export
  and AI proposals reviewed by hunk. Attaching a note captures a saved revision.
  Notes cloud sync is not enabled.
- [Files](../connected-files.md) connects explicitly chosen project-scoped folders
  with read-only access initially, bounded browsing/text editing, selected verified
  imports and immutable AI snapshots. Save edited copy is the default. Original
  replacement requires actual tests on that exact root and app session, a reviewed
  diff and an explicit commit. macOS APFS checks passed; this does not qualify
  other filesystems or hosts.
- [AI orchestration](../parallel-ai.md) runs in a launcher-owned Node executor with
  core-controlled budgets, approvals, global inference admission and cancellation
  fencing. Accepted work can continue after closing the browser while the
  launcher/core remain active. Scientific jobs retain their separate supervisor.

Native packages retain the fixed Files helper source required at startup and for
its versioned HPC protocol. Frozen-core acceptance covers folder browsing,
root qualification and reviewed edited copies with UTF-8 BOM/newline preservation.

Team remains disabled. Real macOS native trials demonstrated overlapping
specialists, but the Node 22 repeat failed its evidence qualification because both
specialists failed. A completed synthesis cannot qualify incomplete tasks. Codex
also remains unqualified. No provider speedup or scientific accuracy is claimed;
unmeasured native usage and cost remain unavailable.

No WSL2 or HPC test host was available. WSL2 `/home` and `/mnt/c`, HPC disconnects,
host-key changes and transfers still require direct qualification. Linux package
checks do not establish those results. Native Windows, realtime multiuser and
cross-device Notes sync remain outside this version's scope.

Publication requires the existing source, native package, browser, solver,
isolation and license gates on macOS ARM64, Linux ARM64 and Linux x64, followed
by fresh installations from npm. No hosted service is deployed by this release.
