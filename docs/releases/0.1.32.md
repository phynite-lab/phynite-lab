# Phynite Lab 0.1.32

Connected HPC clusters show their connection, allocation and runtime details in
separate columns. Compute controls support memory and exact fractional-hour
walltimes, and the workflow canvas offers selected-module resource editing and
clearer run controls.

- Bulk resource edits compare complete allocations and identify mixed settings.
  Selections containing MD keep the supported local compute destination.
- Slurm completion requires an observed terminal state and exit code. Missing
  accounting or controller history stays unresolved; signal exits cannot be
  accepted as successful calculations.
- Automatic band and phonon paths retain every SeeK-path branch. Custom paths
  preserve disconnected branches and reject incomplete branches. Expert raw
  inputs remain authoritative over visual controls.
- Changing numerical accuracy or SOC preserves the selected pseudopotential
  family. Model validation still requires compatible pseudopotentials.
- Execution panels retain numerical summaries, failure diagnostics, trajectories
  and artifact links. DFT configuration also offers grouped output downloads.
  Figure archives preserve distinct directories so equal basenames do not
  overwrite one another.

This release integrates Jauhar Nur Ramadhan's HPC interface work from PR #89
with review fixes. Native package, browser, persistence, scientific reference,
isolation and license checks are required for macOS ARM64, Linux ARM64 and
Linux x64. Exact corresponding source, package checksums and collected evidence
accompany the release. Direct HPC scheduler/SSH behavior is covered by regression
tests; no live HPC host or WSL2 qualification is claimed here.
