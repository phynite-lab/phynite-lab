# Workspace controls and reading

New device layouts open Canvas beside Phynite AI above 900 CSS pixels of content
space, with a 60/40 ratio and 360px minimum panes. At 721–900px a new layout starts
with one pane; an explicit split uses equal widths. At 720px or less the focused
pane is shown and the saved pair is retained. Vertical splits still require 525px
of height. Existing device layouts remain restorable. Closing a tab is navigation;
it does not delete its scientific resource or conversation.

The composer has **+**, a compact model picker, the message, and Send/Stop. Model
selection shows effort only when the model supports more than one choice. **+**
contains context, permissions/strategy, viewport capture, and Discovery presets.
Discovery fills a Plan draft without sending it or starting a calculation. Capture
continues according to the conversation's permission when the menu closes.
Overlays share one owner; Escape restores the trigger. The mobile model picker uses
the existing modal focus trap and scrollable content.

Working status appears beside the response and changes with recorded activity.
Approval waits and connection loss have distinct states. There is no idle task
counter or separate Chat/Tasks tab bar. Specialist activity expands inside the
conversation; technical budgets remain optional. Approval cards identify modules
by their saved names and scientific functions. Exact IDs and checksums remain in
source details. The core retains the verification record without adding a second
self-audit response or historical message-ID checklists to the transcript.

Geist UI and Mono remain the application fonts. Caption/control/body/reading/
section/document sizes start at 12/13/14/16/16/24px. Existing text-size preferences
scale the semantic tokens together. Code has a separate preference; density changes
spacing. Exported scientific figures keep their publication settings.

Parallel inference, connected folders and project Notes have separate contracts
and feature gates. Foreground multistage remains Solo and requires the tab to stay
open; accepted background work uses the durable executor. Actual WSL2 and remote
HPC qualification are separate from browser layout tests.
